# Public release and data ownership

The original application code is MIT licensed (see LICENSE). That permission does not extend to PSE EDGE pages, company reports or other third-party material.

For GitHub, upload the **extracted generated release archive**, not this personal working directory. `python scripts/package_project.py` builds `runtime/release/fundamental-valuation-workbench.zip` with:

- Original code, tests, documentation and synthetic examples.
- Company names/tickers/source links and blank financial templates, not downloaded financial snapshots or report excerpts.
- A clearly labeled synthetic DEMO company for an offline walkthrough.
- No original reports, private scenarios, research histories, cached extraction text or local revision backups.

Personal company brains are preserved on this laptop. Public users can populate their own templates through reviewed imports or manual entry. A blank template is intentional, not a broken data feed. The public release does not assert redistribution rights for downloaded reports or mirror them.

Review the ZIP contents before publishing. This task prepares the project; it does not publish to GitHub. The metadata universe is a saved selection, not a claim of current index membership.
